Bandgap Reference

Overview

Designed and simulated bandgap reference circuits during my Analog Design internship at Omni Design Technologies.

The work included a 1.2 V bandgap reference and an 0.8 V bandgap reference in a 28 nm technology.

1.2 V Bandgap Reference

  • Technology: 28 nm
  • Supply voltage: 1.8 V
  • Reference output: approximately 1.2 V
  • Reference current: approximately 100 µA
  • BJT ratio: 1:8
  • Temperature range: −40°C to 125°C

Design

The circuit combines:

  • CTAT voltage generated using a BJT
  • PTAT voltage generated from the difference in BJT base-emitter voltages
  • Resistor-based scaling
  • Feedback to establish the required operating point

Verification

I performed:

  • PVT analysis
  • Temperature analysis
  • Monte Carlo simulation
  • Supply-voltage variation analysis

What I Learned

This project helped me understand:

  • BJT operation in CMOS processes
  • PTAT and CTAT generation
  • Feedback in bandgap references
  • Device mismatch
  • Temperature dependence
  • PVT corners
  • Monte Carlo analysis
